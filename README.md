# Customer Opportunity Desk

An agentic decision-support prototype for customer growth teams at a (fictional) GCC multi-brand retail group.
AI agents find and explain cross-brand opportunities and draft actions; deterministic code does every calculation
and enforces consent and contact rules; a human approves; the send is simulated and measured against a control group
in **incremental gross margin**.

> Work in progress. All data is synthetic. No real customers, brands or companies.
